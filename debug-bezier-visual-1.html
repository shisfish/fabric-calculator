🔬 Tshirt.ts 核心公式推导

基础参数：
W = fp.width = 29.5 cm （胸围半宽）
L = fp.length = 71 cm （衣长）
neckW = fp.neckWidth = 9 cm （领口宽）
neckD = fp.neckDepth = 5.1 cm （领口深）
shoulderW = fp.shoulderWidth = 12.5 cm （肩宽）
armholeD = fp.armholeDepth = 25 cm （袖窿深）
肩斜计算：
const shoulderSlope = Math.tan((fp.shoulderSlope ?? 12) * Math.PI / 180);
const shoulderDrop = shoulderSlope * shoulderW;

结果：shoulderDrop = tan(12°) × 12.5 = 1.80 cm
袖窿跨度：
const spanX = W - shoulderW;
const spanY = armholeD - shoulderDrop;

结果：spanX = 29.5 - 12.5 = 17.0 cm
      spanY = 25 - 1.80 = 23.2 cm
Pitch 点（袖窿最大外鼓点）：
points.pitch = new Point(
  shoulderW + spanX * 0.32,
  shoulderDrop + spanY * 0.28
);

计算：x = 12.5 + 17.0 × 0.32 = 17.94 cm
      y = 1.80 + 23.2 × 0.28 = 8.30 cm
Hollow 点（袖窿内收点）：
points.hollow = new Point(
  shoulderW + spanX * 0.72,
  shoulderDrop + spanY * 0.72
);

计算：x = 12.5 + 17.0 × 0.72 = 24.74 cm
      y = 1.80 + 23.2 × 0.72 = 18.50 cm

三段Bezier控制点公式

第一段（shoulderPoint → pitch）- 外鼓起始：
points.cp1a = new Point(shoulderW + spanX * 0.10, shoulderDrop + spanY * 0.02);
             = (12.5 + 1.70, 1.80 + 0.464) = (14.20, 2.27)

points.cp1b = new Point(pitch.x - spanX * 0.12, pitch.y - spanY * 0.10);
             = (17.94 - 2.04, 8.30 - 2.32) = (15.90, 5.98)
第二段（pitch → hollow）- 内收：
points.cp2a = new Point(pitch.x + spanX * 0.10, pitch.y + spanY * 0.12);
             = (17.94 + 1.70, 8.30 + 2.784) = (19.64, 11.08)

points.cp2b = new Point(hollow.x - spanX * 0.12, hollow.y - spanY * 0.08); ⚠️ 内收
             = (24.74 - 2.04, 18.50 - 1.856) = (22.70, 16.65)
第三段（hollow → armholeBottom）- 垂直进入腋下：
points.cp3a = new Point(hollow.x + spanX * 0.04, hollow.y + spanY * 0.10);
             = (24.74 + 0.68, 18.50 + 2.32) = (25.42, 20.82)

points.cp3b = new Point(W - spanX * 0.06, armholeD - spanY * 0.04);
             = (29.5 - 1.02, 25 - 0.928) = (28.48, 24.07)
