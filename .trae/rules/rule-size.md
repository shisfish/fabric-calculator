当前项目：

工业服装CAD系统（T恤前片/后片/袖子）。

目标：

根据成衣测量数据，
生成真实工业裁片SVG。

当前阶段：

不是：
AI自由生成图形。

而是：

基于工业模板，
进行参数化版型变换。

==================================================
【核心规则】
==================================================

禁止：

1. 随机生成 polygon
2. 随机生成 Bezier
3. 自由推导 path 拓扑
4. 使用矩形模拟裁片
5. 控制点共线
6. AI自由决定曲线结构

必须：

1. 固定工业拓扑
2. 固定关键点结构
3. 基于比例规则变换
4. 所有曲线来自工业经验参数

==================================================
【工业拓扑规则】
==================================================

前片（半片）固定结构：

M
Q
L
C
C
C
L
Q
Z

含义：

M = 前中领口起点

Q = 前领口Bezier

L = 肩线

C = 袖窿上段
C = 袖窿中段
C = 袖窿下段

L = 侧缝

Q = 下摆轻微弧线

Z = 闭合

禁止：
修改path结构。

==================================================
【坐标系统】
==================================================

使用工业CAD坐标：

x：
向右增加

y：
向下增加

禁止：

负Y坐标。

前中线(FOLD)：

固定：
x = 0

==================================================
【工业经验规则】
==================================================

不是固定值。

必须：

使用比例系统。

--------------------------------------------------
1. 肩斜
--------------------------------------------------

shoulderDrop:

修身：
2~3

常规：
3~4

oversize：
2~3

禁止：
负值。

--------------------------------------------------
2. 袖窿外鼓（CP1）
--------------------------------------------------

目标：

产生工业外鼓效果。

错误：
CP1 与肩点、腋下共线。

正确：

CP1 必须比肩点更外。

使用比例：

cp1.x =
shoulder.x +
(W - shoulder.x) * outwardRatio

规则：

修身：
0.18~0.25

常规：
0.28~0.35

oversize：
0.38~0.48

--------------------------------------------------
3. 袖窿 hollow（CP2）
--------------------------------------------------

目标：

形成工业凹陷。

错误：
CP2 比 underarm 更外。

正确：

CP2 必须内收。

使用比例：

cp2.x =
underarm.x -
(W * hollowRatio)

规则：

修身：
0.10~0.14

常规：
0.06~0.10

oversize：
0.02~0.06

==================================================
【工业袖窿规则】
==================================================

袖窿不是：

一条斜线。

必须：

先外鼓，
再内收。

正确趋势：

shoulder
→ outward curve
→ hollow
→ underarm

禁止：

控制点共线。

禁止：

Bezier退化为直线。
